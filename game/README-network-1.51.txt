Tank: Zone of Death 1.51.3 - сетевая игра
==========================================

Это оригинальная версия 1.51.3 (2010 год), собранная заново под Windows 10/11.
Игра, физика, карты и интерфейс те же. Отличия от старого exe:

  * включён пункт меню "Сетевая игра" и починены ошибки, из-за которых
    автор отключил сеть в версии 1.50:
      - танки других игроков не двигались на их машинах;
      - управление игроков было перепутано местами;
      - при потере фокуса окном игра всех участников вставала.
  * только рендер OpenGL (Direct3D убран, он требовал старый DirectX SDK);
  * звук, управление и всё остальное без изменений.

Как играть по сети
------------------
Все участники должны запускать ОДИН И ТОТ ЖЕ tank.exe из этого архива
(сервер проверяет контрольную сумму exe и карты).

Хост (у кого сервер):
  1. Сетевая игра -> Создать сервер.
  2. Выбрать карту, лимиты, скорость сервера (fps, 30 по умолчанию).
     Галочку "Использовать лобби" НЕ ставить (лобби-серверов давно нет).
  3. ОК. Откроется комната ожидания. Можно добавить ботов и писать в чат.
  4. Когда все подключились, каждый нажимает "Готов". Игра стартует,
     когда готовы все.

Остальные:
  1. Сетевая игра -> Подключиться.
  2. Ввести адрес хоста: IP или IP:порт (порт по умолчанию 1945, TCP).
  3. ОК, затем "Готов" в комнате ожидания.

Профиль игрока (ник, танк, скин): Сетевая игра -> Профиль.
Управление: Настройки -> профили управления (по умолчанию WASD + пробел).

Соединение
----------
Протокол TCP, порт 1945. Через интернет нужен проброс порта на роутере
хоста или виртуальная локальная сеть (ZeroTier, Hamachi и т.п.) - тогда
подключаться по адресу из этой сети.

Параметры командной строки (необязательно)
------------------------------------------
  --config <файл>   файл настроек вместо config.cfg
  --log <файл>      файл журнала вместо log.txt
  --host <карта>    сразу создать сервер на карте (имя файла без .map, например dm1)
  --join <адрес>    сразу подключиться к серверу
  --bots <n>        добавить n ботов после входа в комнату
  --autoready <n>   нажать "Готов" автоматически, когда в комнате n игроков

Пример двух экземпляров на одном компьютере для проверки:
  tank.exe --host dm1
  tank.exe --config client.cfg --log client.log --join 127.0.0.1

Исходники: ветка legacy-1.51 в репозитории, сборка CMake + Visual Studio 2022.
